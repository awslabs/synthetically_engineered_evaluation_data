# Archive

Frozen records, kept for the *why* behind decisions already made. Nothing here
describes how the code works today — for that, read `docs/docs/` (the published
site) or the code.

These files are not part of the MkDocs build (`docs_dir` is `docs/docs/`).

| Directory | What it records |
|---|---|
| `planning/` | The SEED unification effort (#14, PR #15): the five-milestone execution plan and the response to the first round of review on that PR |

Paths written inside these documents refer to their locations at the time of
writing — `docs/planning/…` is now `docs/archive/planning/…`. They are left
unedited on purpose: a historical record that gets updated is no longer one.
